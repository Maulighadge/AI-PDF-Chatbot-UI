# AI-PDF-Chatbot-UI

Modern React interface for the AI PDF Chatbot.

## Features
- **Modern Dark UI**: Glassmorphism, tailored typography, custom scrollbars
- **Real-Time Backend Status**: Live polling of FastAPI backend
- **PDF Upload & Drag-and-Drop**: Client-side parsing and server-side ingestion
- **Citation Badges**: Traceable page citations for each AI answer
- **Document Manager**: Multi-document switching and document metadata viewer

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Accessible at `http://localhost:5173`.
